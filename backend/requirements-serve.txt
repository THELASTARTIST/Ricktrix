# server never imports tensorflow. That is the difference between a ~150 MB
# image that cold-starts in milliseconds and a ~1.2 GB one that takes a minute
# to import, and it is why the free tier of most hosts is enough.
#
# TensorFlow lives in requirements.txt, which is what you install to *train*.
# Both can be installed in the same virtualenv without conflict.
